Updating Snow Crows Builds (without scraping)
==============================================

Use this workflow when SC updates a build and you want to edit it manually
in the addon instead of re-scraping.


CACHE DIRECTORY (on the Windows GW2 machine)
---------------------------------------------
  [GW2 addon dir]\addons\BuildCoach\cache\


FILES IN CACHE
--------------
  sc_builds_full.json          - combined file, all professions (full data)
  sc_builds_guardian.json      - per-profession file (written by scraper)
  sc_builds_warrior.json         these take PRIORITY over sc_builds_full.json
  sc_builds_engineer.json        for their respective profession
  sc_builds_ranger.json
  sc_builds_thief.json
  sc_builds_elementalist.json
  sc_builds_mesmer.json
  sc_builds_necromancer.json
  sc_builds_revenant.json
  sc_builds.json               - summary-only fallback (no gear/traits)


LOAD PRIORITY (LoadSCBuilds reads in this order)
-------------------------------------------------
  1. Per-profession files  (sc_builds_<prof>.json)  -- WIN if present
  2. sc_builds_full.json   (fills professions not covered by per-prof files)
  3. sc_builds.json        (last-resort fallback, no gear/traits)


HOW THE BUILDS ARE STORED
--------------------------
  The SC builds are EMBEDDED inside the DLL itself (src/sc_builds_embedded.h).
  On first load, if the DLL's embedded version number is higher than the version
  stored in the cache, the DLL extracts its embedded JSON to cache\sc_builds_full.json
  and overwrites whatever was there.

  This means: if you edit builds but don't bump the version and rebuild the DLL,
  the next DLL install will wipe your edits. You MUST use --regen when rebuilding.


HOW TO EDIT A BUILD MANUALLY — FULL WORKFLOW
---------------------------------------------
  ON WINDOWS (in-game):
    1. Open the addon → Build Editor
    2. In the "SC builds" row: use profession/type filters or search to find the build
    3. Make your changes in the form (traits, skills, gear, etc.)
    4. Click "Resolve & Save"
       → Writes ALL builds to: [addon dir]\addons\BuildCoach\cache\sc_builds_full.json
    5. Delete the per-profession file for the profession(s) you edited, e.g.:
       [addon dir]\addons\BuildCoach\cache\sc_builds_necromancer.json
       (otherwise the old per-prof file takes priority on reload)

  ON LINUX (dev machine):
    6. Copy sc_builds_full.json from the Windows cache to the project root
       (overwrite the existing one)
    7. Delete sc_builds_<edited_prof>.json from the project root too
       (so --regen doesn't re-merge it and overwrite your edits)
    8. Run:  build.sh --regen
       → merges any remaining per-prof files, BUMPS VERSION NUMBER,
         re-embeds the JSON into src/sc_builds_embedded.h
    9. Run:  build.sh
       → compiles the new DLL

  ON WINDOWS (deploy):
   10. Replace BuildCoach.dll with the newly built one
       → on first load it sees the higher version, extracts embedded JSON to cache


  *** --regen is mandatory. --clean alone is NOT enough. ***
  Without --regen the version number stays the same and the DLL won't
  overwrite the cache file on the next install.


SCRAPING (still available for full updates)
-------------------------------------------
  Snow Crows allows occasional scraping — use the scraper for full profession
  refreshes when many builds change at once. Use the Build Editor for small
  targeted edits in between.
