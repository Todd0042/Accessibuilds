Version format: x.y.z

  x  Major version  — increments with --major flag, resets y and z to 0
  y  Minor version  — increments on every build, resets to 0 when --major is used
  z  Patch version  — increments when default_builds.json is updated via --regen

Commands:

  ./build.sh                 Normal build        y++          e.g. 1.1.0 -> 1.2.0
  ./build.sh --regen         Builds data update  y++ and z++  e.g. 1.2.0 -> 1.3.1
  ./build.sh --major         Major release       x++, y=0, z=0  e.g. 1.3.1 -> 2.0.0
  ./build.sh --major --regen Major + data update x++, y=0, z=0  e.g. 2.0.0 -> 3.0.0

The current version is stored in version.txt at the project root.
It is read by CMake at build time and embedded into the DLL via version_data.h.
